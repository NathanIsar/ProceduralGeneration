Procedural Generation
===
Ce dépôt regroupe notre semaine théorique de génération procédurale.
Nous avons pu apprendre et coder nos propres algorithmes de génération procédurale à travers diverses techniques.
Dans ce dépôt, vous pourrez retrouver des explications ainsi que le code des algorithmes Simple Room Placement, Binary Space Partition, Cellular Automata et Noise Generator.
